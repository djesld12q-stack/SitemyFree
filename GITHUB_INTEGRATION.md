# GitHub Інтеграція — Управління Контентом

Це система для управління скриптами, посиланнями та іграми через GitHub API без необхідності в бекенді.

## 🔧 Налаштування

### 1. GitHub Repository Setup

Переконайтеся, що в вашому репозиторії є ці JSON файли:
- `scripts.json` — список скриптів
- `links.json` — список посилань  
- `games.json` — список ігор

Ці файли будуть автоматично синхронізовані при редагуванні.

### 2. Personal Access Token

1. Перейдіть на https://github.com/settings/tokens
2. Натисніть **"Generate new token"** → **"Generate new token (classic)"**
3. Додайте опис (наприклад: "sunwukong-admin")
4. Виберіть scopes:
   - ✅ `repo` (повний доступ до репозиторія)
   - ✅ `read:user` (читання профілю)
5. Натисніть **"Generate token"**
6. **Скопіюйте токен** (він більше не буде видимий!)

### 3. Вставлення токена

Коли ви авторизуєтеся через Twitch як **sun69wukong**, система попросить вас ввести токен:

```
Введіть GitHub Personal Access Token:
(Токен буде збережений локально)
```

Вставте ваш токен, і він буде збережений в `localStorage` браузера.

## 📝 Управління контентом

### Додавання скрипту

1. Авторизуйтеся через Twitch
2. На сторінці скриптів натисніть кнопку **"+ ДОДАТИ"**
3. Заповніть форму:
   - **НАЗВА СКРИПТУ** — назва скрипту
   - **ОПИС** — короткий опис функціональності
   - **URL ЗОБРАЖЕННЯ** — посилання на картинку
   - **URL ЗАВАНТАЖЕННЯ** — посилання на скрипт
4. Натисніть **"ЗБЕРЕГТИ"**

Новий скрипт буде додано в `scripts.json` на GitHub.

### Редагування скрипту

1. Наведіть мишку на карточку скрипту
2. Натисніть кнопку **"✏ EDIT"**
3. Змініть потрібні поля
4. Натисніть **"ЗБЕРЕГТИ"**

### Видалення скрипту

1. Відкрийте скрипт для редагування
2. Натисніть **"ВИДАЛИТИ"**
3. Підтвердіть видалення

## 🔒 Безпека

⚠️ **ВАЖЛИВО:**

- **Ніколи не діліться токеном** публічно
- Токен зберігається тільки в `localStorage` браузера (не відправляється на сервер)
- Якщо ви випадково поділилися токеном:
  1. Негайно зайдіть на https://github.com/settings/tokens
  2. Видаліть скомпрометований токен
  3. Створіть новий

## 🐛 Вирішення проблем

### "GitHub токен не встановлений"
- Переконайтеся, що ви авторизовані як **sun69wukong** через Twitch
- Вставте токен, коли система запросить

### "Помилка при збереженні"
- Перевірте, що токен має права на запис (`repo` scope)
- Перевірте інтернет-з'єднання
- Переспробуйте операцію

### "Файл не знайдений на GitHub"
- Переконайтеся, що `scripts.json`, `links.json` і `games.json` існують в репозиторії
- Якщо файли відсутні, вони будуть автоматично створені при першому збереженні
